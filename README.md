# Carte de visite numérique ElectroZizo

Site statique responsive prêt pour GitHub Pages. Il ne nécessite aucune installation ni compilation.

## Publication sur GitHub Pages

1. Créez un nouveau dépôt GitHub vide.
2. Ajoutez tous les fichiers de ce dossier à la racine du dépôt.
3. Envoyez-les sur la branche `main`.
4. Dans **Settings → Pages**, choisissez **GitHub Actions** comme source.
5. Le workflow inclus publiera automatiquement le site.

## Aperçu local

Ouvrez `index.html` directement, ou servez le dossier avec un petit serveur HTTP local.
